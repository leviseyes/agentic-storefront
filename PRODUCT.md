# Agentic Storefront

An MIT-licensed, single-product conversation-first storefront starter. The user talks, types or taps; the agent presents relevant product views and changes a cart after explicit intent. The left visual/cart stage never covers the right conversation.

The default merchant Studio, product Studio Mount, guide Alex, sample price and product specifications are fictional. The demo is useful without API keys, accounts or real orders. Configured OpenAI, xAI, ElevenLabs and Shopify adapters enable live services independently.

Success means a new developer can run the demo, understand its boundaries, replace merchant content, and test cart behavior without spending money. No guaranteed conversion lift, latency target, human identity or star count is claimed.

Preserve the inherited warm paper / Manrope / brown accent design language. This release adapts the existing interface to public sample content rather than replacing its composition.
