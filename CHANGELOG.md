# Changelog

## 0.1.0

First public edition of Agentic Storefront.

- Keyless, clearly labeled demo with fictional merchant content and a local sample cart.
- Conversation-led product views, procedural 3D inspection, and a local walkthrough with follow-up.
- Optional OpenAI text/image, xAI realtime voice, ElevenLabs speech, and Shopify Storefront adapters.
- Server-side cart consent and quantity handling, private anonymous sessions, and constrained checkout redirects.
- React + Vite + Cloudflare Worker runtime with D1/R2 local emulation.
- MIT license, setup and deployment docs, contribution templates, and automated checks.

Initial validation: 144 deterministic tests, TypeScript, production build, six Shopify GraphQL operations, and desktop/mobile rendered checks. Provider tests use mocks; the public edition includes no shared paid API access or hosted demo.
