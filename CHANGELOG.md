# Changelog

## 0.2.0 — General commerce preview

- Replaced the single-product wall-mount core with a category-neutral merchant catalog.
- Added outdoor and coffee examples using the same runtime and configuration contract.
- Added multiple products, variants, comparisons, stock states and multi-line carts.
- Added configured image/model views and optional merchant photo/video tools.
- Unified explicit cart authority for text and realtime voice; added durable total targets and request deduplication.
- Reworked setup and architecture documentation for merchants adapting the starter.

This remains a preview starter. Provider-backed audio and real Shopify checkout require staging verification with your own accounts.

## 0.1.0 — Initial public preview

MIT-licensed extraction with a fictional single-product home-decor demo, voice/chat, visual tools and optional Shopify checkout. Superseded by the category-neutral 0.2 architecture.
